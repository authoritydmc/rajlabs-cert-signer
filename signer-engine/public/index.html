Offline Root CA & Intermediate Signer Guide

Strict Zero-Trust security: Keep your Root CA on an air-gapped machine or encrypted drive, and only import signed intermediates into this UI.

Step 1: Generate Root CA (Run on Offline Computer)

Generate 4096-bit RSA key and 20-year self-signed certificate:

openssl genrsa -out root-ca.key.pem 4096
openssl req -new -x509 -days 7300 -key root-ca.key.pem -out root-ca.cert.pem \
  -subj "/C=IN/ST=Karnataka/L=Bengaluru/O=Enterprise/CN=Enterprise Root CA"

⚠️ Store root-ca.key.pem in a secure vault or offline USB. NEVER import it into Docker!

Step 2: Generate Intermediate CA Signer Key & CSR

openssl genrsa -out int-server.key.pem 4096
openssl req -new -sha256 -key int-server.key.pem -out int-server.csr.pem \
  -subj "/C=IN/ST=Karnataka/L=Bengaluru/O=Enterprise/CN=Enterprise Server Intermediate CA"

Step 3: Sign Intermediate with Root CA (Offline)

# Create extension file: ext.cnf
echo "basicConstraints = critical, CA:true, pathlen:0" > ext.cnf
echo "keyUsage = critical, digitalSignature, cRLSign, keyCertSign" >> ext.cnf

openssl x509 -req -in int-server.csr.pem -CA root-ca.cert.pem -CAkey root-ca.key.pem \
  -CAcreateserial -out int-server.cert.pem -days 3650 -sha256 -extfile ext.cnf

Step 4: Import into this Web UI

Copy int-server.cert.pem, int-server.key.pem, and root-ca.cert.pem. Go to the Intermediate CAs tab above and click + Import Intermediate CA. The private key will be stored securely using AES-256 encryption.
